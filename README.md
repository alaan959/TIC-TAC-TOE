# TIC-TAC-TOE
El juego del tres en raya, pero en web!

README – Projecte Tic Tac Toe

En aquest document explico, de manera molt senzilla, com he desenvolupat el joc del Tic Tac Toe utilitzant HTML, CSS i JavaScript. Explico el procés des del principi i pas a pas.

Idea del projecte

L’objectiu del projecte és crear el joc clàssic del Tic Tac Toe (tres en ratlla) per a dos jugadors. Un jugador juga amb X i l’altre amb O. Els jugadors fan clic a les caselles del tauler per torns.

El projecte està format per tres arxius:

index.html: estructura de la pàgina

style.css: disseny i estils

script.js: funcionament del joc

Desenvolupament de l’HTML

Primer vaig crear l’arxiu index.html. En aquest punt només em vaig centrar en l’estructura del joc.

Al HTML he creat:

Un contenidor principal per al joc.

Un tauler amb 9 caselles (botons), que representen el joc.

Un text informatiu per mostrar el torn del jugador.

Un botó per reiniciar la partida.

Les caselles tenen una mateixa classe per poder-les controlar fàcilment amb JavaScript.

Desenvolupament del CSS

Després vaig treballar amb l’arxiu style.css per donar-li forma al joc.

Amb el CSS he fet:

Centrar el joc a la pantalla.

Crear el tauler amb una graella de 3x3.

Donar una mida clara a les caselles perquè es vegin bé.

Ajustar colors i espais perquè el joc sigui senzill i entenedor.

Desenvolupament del JavaScript

L’arxiu script.js controla el funcionament del joc.

He fet:

Control del torn del jugador (X o O).

Escriure la X o la O quan es fa clic a una casella.

Evitar que es pugui jugar en una casella ja ocupada.

Un botó per reiniciar el joc i començar una nova partida.

Tot el codi és senzill i pensat per entendre’s fàcilment.
